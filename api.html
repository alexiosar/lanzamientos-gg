API PÚBLICA

El calendario completo de lanzamientos de videojuegos en español, en JSON. Sin registro, sin clave de acceso, sin límite de peticiones y con CORS abierto, así que podés consumirla directamente desde el navegador. Se actualiza todos los días.

ENDPOINTS

GET https://lanzamientos.lat/api/juegos.json

El calendario completo: todos los juegos cargados, pasados y futuros.

GET https://lanzamientos.lat/api/proximos.json

Solo los lanzamientos de los próximos 30 días. Mismo formato, mucho más liviano.

GET https://lanzamientos.lat/rss.xml

Las últimas novedades del calendario en formato RSS 2.0.

ESPECIFICACIÓN OPENAPI

El contrato completo de la API está publicado en formato OpenAPI 3.1:

▸ /api/openapi.yaml

Con ese archivo podés importar la API de un clic en Postman, Insomnia o Bruno, o generar automáticamente un cliente en el lenguaje que uses. Describe los dos endpoints, los tipos de cada campo y qué campos son opcionales.

EJEMPLO
fetch("https://lanzamientos.lat/api/proximos.json")
  .then(r => r.json())
  .then(d => {
    d.juegos.forEach(j => {
      console.log(j.fecha, j.titulo, j.plataformas.join("/"));
    });
  });
RESPUESTA

La raíz es un objeto con metadatos y un array juegos:

{
  "sitio": "LANZAMIENTOS.LAT",
  "descripcion": "Calendario de lanzamientos de videojuegos en español",
  "url": "https://lanzamientos.lat",
  "generado": "2026-07-29",
  "licencia": "Uso libre citando la fuente con un enlace a lanzamientos.lat",
  "contacto": "contacto@lanzamientos.lat",
  "juegos": [ ... ]
}

proximos.json agrega además desde y hasta (el rango de fechas que cubre) y total (la cantidad de juegos que devuelve).

LICENCIA Y LÍMITES

Uso libre, incluso comercial, citando la fuente con un enlace a lanzamientos.lat. No hay límite de peticiones, pero los archivos son estáticos y se regeneran una vez por día: no tiene sentido consultarlos más seguido que eso.

Las fechas las anuncian las editoras y pueden cambiar sin aviso. Los datos se elaboran manualmente a partir de fuentes públicas y se ofrecen sin garantías.

QUÉ HACE Y QUÉ NO

Se dibuja justo donde pusiste la etiqueta y toma el ancho del contenedor, así que se adapta a tu diseño. No usa un iframe.

Se dibuja dentro de un Shadow DOM, así que está aislado: el CSS de tu sitio no puede entrar y el suyo no puede salir. Lo probamos contra una página con reglas agresivas (a { color: crimson !important }, itálicas y bordes redondeados forzados) y el widget se ve igual que acá.

No usa cookies, no guarda nada y no rastrea a tus visitantes. Hace una sola petición a un archivo JSON estático. Si esa petición falla, no te deja un bloque roto: muestra solo el enlace.

Pesa menos de 4 KB y no depende de ninguna librería.

CONDICIONES

Uso libre, también en sitios comerciales. La única condición es dejar el enlace a lanzamientos.lat que viene al pie del widget.

Si preferís armar algo a medida, están la API pública y su especificación OpenAPI.
